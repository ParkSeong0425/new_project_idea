토트 속 상품이 2층 AGV에 오르기까지

상품 하나가 토트 → 놓기판 → 스캔 터널 → 리프트 → AGV로 넘어가는 과정을 느리게 보여 줘요. 위에서 "1단계 · 사람"과 "2단계 · 로봇"을 바꿔 보세요. 둘의 차이는 토트에서 하나 꺼내 놓기판에 놓는 손 하나뿐이고, 놓기판부터 뒤는 똑같아요.

스캔 터널에서 리프트로 넘어가는 순간

비밀은 "벨트 높이를 맞추고, 같이 돌리는 것"이에요. 에스컬레이터에서 바닥으로 내릴 때처럼, 리프트가 받는 높이에서 기다리고 있다가 두 벨트가 같은 속도로 돌면 상품이 이어서 미끄러지지 않고 옮겨 타요. 리프트 위의 짧은 벨트를 벨트 캐리어라고 불러요.

넘어가는 곳어떻게무엇으로 확인
놓기판 → 터널두 벨트 높이가 같고 끝이 1~2cm 간격. 같은 속도로 돌아요터널 입구 광센서 (상품 길이도 잼)
터널 안벨트 두 개 사이 2cm 틈 아래에서 카메라가 바닥면 라벨을 봐요카메라 4~6대가 같은 순간 촬영
터널 → 리프트리프트가 85cm에서 기다리다, 벨트 캐리어를 터널 벨트와 같이 돌려 받아요캐리어 위 광센서 "상품 들어옴"
터널 → 예외함판정이 "못 읽음"이면 터널 끝 플랩이 아래로 열려 예외함으로 떨어져요예외함 센서
리프트 → AGV목적지 층 높이로 올라간(내려간) 뒤 AGV 도착 신호를 받고 캐리어 벨트를 돌려 밀어 넣어요AGV 트레이 센서 → 관제에 "실었음"

리프트는 3D 로더의 Y축(승강) 구조와 같아요. 기둥 2개 + 벨트 구동 + 서보, 원점은 토크 원점. 벨트 캐리어는 TILT 대신 짧은 컨베이어를 단 것이라고 보면 돼요.

"작업자 없이 토트에서 하나씩"은 어떻게?

정확하게 짚었어요. 토트에서 상품을 하나만, 망가뜨리지 않고 꺼내는 일은 이 장치에서 가장 어려운 일이고, 기계만으로는 깔끔한 방법이 없어요. 그래서 1단계는 이 일만 사람이 하고, 2단계에서 이 자리를 로봇(갠트리 + 흡착 + 3D 카메라)으로 바꾸는 거예요. 놓기판은 "사람 손 → 로봇 손"을 바꿔 끼우는 경계선이에요. 놓기판부터 뒤가 같으니까, 1단계 장치를 팔다가 그 앞에 로봇만 붙이면 2단계가 돼요.

꺼내는 방법어떻게화장품 · 섞인 상품이 제안에서
사람토트에서 집어 놓기판에 아무 방향으로 놓음가장 확실1단계 바코드 · 층 맞추기는 장치가 대신해서 사람이 빨라짐
갠트리 + 흡착 로봇3D 카메라가 위에서 보고, 맨 위 상품의 평평한 면을 흡착해 하나씩 놓기판에상자 · 화장품 상자 잘 됨 병 · 망 포장은 어려움2단계 토트는 현장 컨베이어로 직접 들어옴
기울여 쏟고 진동으로 펼치기토트를 기울여 쏟은 뒤 진동판으로 한 겹으로깨짐 · 엉킴제외 (지난 버전에서 뺌)
계단식 싱귤레이터속도가 다른 컨베이어 여러 개로 뭉친 것을 간격 벌려 한 줄로택배 상자용 작은 상품은 부적합참고만
2단계에서 토트는 어떻게 들어오나

현장의 컨베이어(자동창고나 피킹 구역에서 오는 줄)를 셀 입구에 이어 붙여요. 토트가 집는 위치에 멈추면 갠트리가 다 꺼내고, 빈 토트는 같은 줄의 다른 쪽으로 나가요. 컨베이어가 없는 현장만 버퍼 컨베이어나 기성품 운반 로봇(AMR)을 붙여요.

3D는 개념 모델이에요(치수 예시: 작업 높이 85cm, 2층 AGV 트레이 약 2m). 실제 소터의 AGV 높이와 정지 위치로 다시 맞춰야 해요.
